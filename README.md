# Dynamic GIS Recommender: demo ประกอบการเสนอเค้าโครง

ต้นแบบตามเอกสาร `เค้าโครงโครงงานฉบับสมบูรณ์` (ข้อ 3.1–3.4, 5.1–5.9, 6) แนะนำเส้นทางเดินภายในมหาวิทยาลัยขอนแก่น
เปรียบเทียบ Shortest Path, Fixed Context-Weighted Score, LinUCB และการปรับใช้ตามแนวคิด dLinUCB บนข้อมูลจำลอง

## ติดตั้ง (ครั้งแรกบนเครื่องใหม่)

ต้องมี Python 3.12 ขึ้นไป (ทดสอบบน 3.13) แล้วรันในโฟลเดอร์นี้:

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
```

บน macOS หรือ Linux ใช้ `.venv/bin/python` แทน `.venv/Scripts/python`
ข้อมูลกราฟ มข. ผลทดลอง และค่าที่สอบเทียบอยู่ใน `data/` กับ `results/` แล้ว ไม่ต้องรันใหม่ก็เปิด demo ได้

## วิธีเปิด

ดับเบิลคลิก `run_demo.bat` เบราว์เซอร์จะเปิดที่ http://localhost:8501

ไม่ต้องใช้อินเทอร์เน็ต ยกเว้นภาพพื้นหลังแผนที่ ถ้าไม่มีเน็ต ให้ปิดช่อง "แสดงแผนที่พื้นหลัง" ระบบจะวาดเฉพาะเส้นทางเดินของ มข.

## ขั้นตอนสร้างผลทั้งหมดใหม่ (ทำซ้ำได้ตามข้อ 3.1)

```bash
.venv/Scripts/python prep_data.py          # ดึงกราฟทางเดินและสถานที่จาก OpenStreetMap (ต้องใช้อินเทอร์เน็ต)
.venv/Scripts/python select_od_pairs.py    # เลือกและบันทึกคู่ต้นทาง–ปลายทางกับเส้นทางทางเลือก (ข้อ 5.2.2)
.venv/Scripts/python experiments.py calibrate   # สอบเทียบด้วย Seed 1000–1009 เท่านั้น (ข้อ 5.5, 5.7)
.venv/Scripts/python experiments.py run         # ทดลองจริง Seed 0–29
.venv/Scripts/python experiments.py analyze     # ตัดสิน H1–H3 ตามตารางที่ 6
.venv/Scripts/python experiments.py sensitivity # ความไวของ ε ใน Adaptation Time บน Seed สอบเทียบ (ไม่ใช่ผลหลัก)
```

ชุดทดสอบ:

```bash
PYTHONPATH=. .venv/Scripts/python -m pytest -q tests
```

## ไฟล์

| ไฟล์ | หน้าที่ | ข้อในเอกสาร |
|---|---|---|
| `config.yaml` | ค่าทั้งหมด พร้อมระบุว่ามาจากข้อไหน หรือเป็นค่าที่ผู้จัดทำกำหนดเอง | 5.1.4 |
| `sim.py` | กราฟ เส้นทาง บริบท Reward นโยบาย 4 แบบ และตัวชี้วัด | 5.2–5.5, 5.8 |
| `experiments.py` | สอบเทียบ ทดลอง 30 Seed และตัดสินสมมติฐาน | 5.5–5.9 |
| `app.py` | หน้าจอต้นแบบ (Streamlit, แผนที่ Folium, กราฟ Matplotlib) | 3.4, 5.1.2–5.1.3 |
| `data/` | กราฟ สถานที่ คู่ต้นทาง–ปลายทาง และค่าที่สอบเทียบ | 5.2 |
| `results/` | `summary.csv` ผลทุกรัน · `curves.npz` เส้นโค้ง Regret · `hypotheses.json` ผล H1–H3 | 5.1.3 |
| `tests/` | ชุดทดสอบอัตโนมัติ | 3.1 |

## สิ่งที่ต้องรู้ก่อนนำเสนอ

- ความหนาแน่นของผู้คนและความชอบของผู้ใช้เป็นค่าจำลองทั้งหมด
- ตัวเลขเป็นผลนำร่องด้วยค่าเบื้องต้น ไม่ใช่ผลการทดลองฉบับสมบูรณ์ (ตามแผน การทดลองจริงอยู่ช่วง ม.ค.–ก.พ. 2570)
- มีสองชุดค่า: "ตามเอกสาร" ใช้ตารางที่ 4 ตรงตัว ซึ่งทำให้ทางสั้นที่สุดดีที่สุดเกือบทุกรอบ จึงมีชุด "หลังสอบเทียบ" ตามข้อ 5.6
  เหตุผลและเกณฑ์อยู่ในหน้า ⑤ ของ demo และใน `config.yaml`
- เรียกว่า "การปรับใช้ตามแนวคิด dLinUCB" ตามข้อ 5.5 เพราะดัดแปลงจาก Algorithm 1 ของ Wu, Iyer และ Wang (2018): การเลือกเส้นทางใช้ α ที่สอบเทียบ (ตารางที่ 3) ส่วนการทดสอบความผิดพลาดใช้ขอบความเชื่อมั่นตามต้นฉบับ
- ไม่ได้ทำ: กรณีแนะนำสถานที่ และการวิเคราะห์ H2 ตามขนาดการเปลี่ยนของ θ
